# [22-131. Installation: Install YOLOv10 in CPU Mode](https://icomerauk.udemy.com/course/yolo-masterclass-deep-learning-computer-vision-course/learn/lecture/45362053#overview)

## Installation

[Clone YOLOv10 repository](https://github.com/THU-MIG/yolov10)

```shell
pip install -r requirements.txt
pip install -e .  # Install the project in editable (development) mode.
```

## Test the installation

```shell
python app.py
```

Copy the URL then open in a browser.
